# Support

Open **Settings → Feedback → Report Issue** in the standalone player or desktop
plug-in to open the [GitHub bug form](https://github.com/appdess/dessamp-player/issues/new?template=bug_report.yml).
A verified GitHub account is required to submit. For private feedback, including
from players without a GitHub account, choose **Email** to compose a message to
[info@dessmetal.com](mailto:info@dessmetal.com). In an iOS AUv3 host, Feedback
can copy the issue URL or email address for use outside the host. Feedback is
sent only when the player submits the form or sends the email.

For a feature idea, use the [feature request form](https://github.com/appdess/dessamp-player/issues/new?template=feature_request.yml).

Never attach credentials, signing material, private capture audio, hidden audit
references, commercial model packages, cabinet IRs, cloud ledgers, or personal
filesystem paths. Follow `SECURITY.md` for suspected vulnerabilities instead
of filing a public issue.

Tone preference and numerical correctness are different questions. A report
about sound should identify the exact package/hash, control settings, cabinet
path, sample rate, host, and level-matching method, while respecting the model
and audio redistribution boundary.
