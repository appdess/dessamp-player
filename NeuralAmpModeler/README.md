# DessAmp plug-in source

This directory contains the iPlug2 application, Audio Unit, VST3, resources,
installer definitions, and platform projects for DessAmp.

Use the repository-level [README](../README.md),
[architecture](../docs/architecture.md), and
[training runbook](../docs/training-runbook.md) for current build and exact
staged-player validation commands. This independent experiment has no public
release guide yet; signing, installation, notarization, and publication remain
explicit owner gates.
